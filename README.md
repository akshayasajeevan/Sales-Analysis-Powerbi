# Sales Performance

## 📌 Project Overview

This project was completed as part of a **Power BI Codethon Assignment**.

The objective was to clean, transform, analyze, and visualize a sales dataset using **Microsoft Power BI** and create an interactive dashboard for business performance analysis.

## 🛠️ Tool Used

- Microsoft Power BI

## 🧹 Data Cleaning & Preparation

The dataset was cleaned and prepared directly in Power BI.

Key steps included:

- Checked the dataset for missing and blank values.
- Used **Find & Replace** to handle inconsistent values.
- Replaced missing numeric values using the **Median** where appropriate.
- Handled blank values in **Sales, Profit, and Cost** fields.
- Filled missing date values using the appropriate nearby date.
- Checked for duplicate records.
- Removed unnecessary fields where required.
- Corrected data types and formatting.
- Created calculated columns, table and measures using **DAX**.
- Prepared the final dataset for visualization.

## 📊 Dashboard & Visualization

### 4. Regional Analysis

### 5. Key Insights & Actions
Presents the major findings and business recommendations based on the analysis.

## 🔍 Key Findings

- Total sales reached approximately **94M**.
- Total profit was approximately **5M**.
- The dataset contains approximately **1K orders**.
- **Furniture** slightly leads Electronics in total sales.
- **December** recorded the highest monthly sales.
- **September** recorded the lowest monthly sales.
- **East** performed strongly in regional orders and profit.
- **North** recorded the lowest regional profit.
- **Monitor and Laptop** were among the leading products by order volume.
- **Laptop** recorded the highest profit among the products shown.

## 💡 Recommendations

- Focus on high-performing products such as **Monitor and Laptop**.
- Use targeted promotions during lower-performing months.
- Maintain strong performance in **East and South** regions.
- Develop strategies to improve lower-performing regions.
- Monitor product-level profitability to support better business decisions.

## 🎯 Project Outcome

The project transformed the raw sales dataset into an **interactive Power BI report** that provides clear insights into sales, profit, products, categories, and regional performance.

The dashboard supports better understanding of business trends and helps identify areas for improvement.
